The project is a desktop application, let's call it Proximo, designed to automate the process of creating a proxy DLL.

A proxy DLL acts as a middleman. When an application tries to load a legitimate DLL, the proxy DLL intercepts the call, allowing you to execute your own code before forwarding the call to the original DLL. This is useful for various tasks like debugging, monitoring function calls, or injecting custom logic.

The app's main purpose is to remove the manual effort involved in this process. You'll be able to select a running process, and the app will automatically find its DLLs and analyze their functions. From there, you can choose which specific functions you want to proxy. Finally, the app will generate a complete Visual Studio project template with a CMakeLists.txt file, ready to compile a new proxy DLL with all your chosen functions already defined.

Overall Concept: The Automated Flow
Instead of a multi-stage wizard, the app will be built around a single, dynamic dashboard. The user will select a process and the app will instantly populate the screen with all the necessary information, ready for the final step of project generation.

Process Selection: User chooses a process from a drop-down list or a search bar.

Instant Analysis: As soon as a process is selected, the application automatically enumerates its DLLs and parses their exports/imports.

Function Filtering & Selection: All functions from all DLLs are displayed in a single, filterable list. The user can filter by DLL name or function name, and then select the functions to be proxied.

One-Click Generation: A single button click generates the CMakeLists.txt file and other necessary project files based on the user's selections.

Generation Options Section:
